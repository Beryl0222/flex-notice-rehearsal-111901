# 虚拟电厂演练中自然语言调节通知的作用域（本地文本演练台）

一个用 Node.js 标准库实现的本地文本演练台：把值班中收到的中文调节通知按发话时间回放，
解析每条通知作用的**时间、量、资源范围与例外**，维护各站点自由容量与承诺生命周期，
对解释不清的句子列出多种可能并挂起，产出供人工阅读的响应草稿与可核查记录。

> 全部电力设施、档位、编号与消息均为合成虚构内容；演练台不连接、不控制任何设备，
> 输出只供人工练习与核对。

## 资料口径

资料保存在 `data/inputs.json`（UTF-8 JSON）：

- `notices`：通知，含发话人、带偏移的发送时间（可跨午夜）与原句文本。
- `resources`：资源的站点、别名、类别与原始容量；容量为演练单位。
- `offers`：协调员意向，区间含起点、不含终点；`kind` 区分整组（`group`，带 `groupId`/`segmentIndex`）
  与逐段独立（`independent`）；可带 `alternatives` 替代时段；`confirmedAt` 表示演练开始前已确认的基线承诺。
- `roles`：演练参与者权限——`issue`（发起调节）、`revise`（更正/撤回已确认承诺）、
  `respond`（协调员响应，受 `resourceIds` 限定）、`confirm`（值班确认）、`resolve`（值班裁定歧义）。

## 运行

环境为 Node.js 22.23.4，仅使用标准库。

```sh
npm run inspect:data     # 列出资料记录数
npm run rehearsal        # 回放全部通知，产出报告到 output/
npm test                 # 运行规则测试
```

带交接回查时点（按演练时点回查收到什么、确认过什么、占用如何变化）：

```sh
npm run rehearsal -- --at "2026-08-02T00:20:00+08:00"
node scripts/rehearsal.mjs --data 其它资料.json --out-dir 目录 --json-only
```

输出（写入 `output/`，该目录已被 git 忽略）：

- `rehearsal-report.txt` / `.json`：逐条通知的响应草稿、意向台账、站点自由容量、歧义清单、待裁定申请、事件流水。
- `handover.txt` / `.json`：指定 `--at` 时的交接回查，容量与状态按事件流重建到该时点（非最终态）。

## 演练台如何处理关键值班情形

- **跨午夜时间**：相对时间按发话时刻解释（“20 分钟后”）；“HH:MM”按发话当日解释，
  早于发话时刻逾 6 小时则视为次日；“更正前条”沿用被引用通知当时的时间口径。
- **作用域与例外**：商区词、站点全称、别名分别解析；共享别名（如“前站”同时指前湾东/西）
  列为多义候选；“医疗/医院类除外”按资源所属站点的类别剔除。
- **可回溯**：解析出的时间、量、资源都保留来源小句（`clauseRefs`），占用都带 `hold:<意向>` 来源。
- **歧义挂起**：一句多种合理解释时，列出每种解释涉及的资源与时段，**只暂缓该歧义可影响的承诺**
  （容量暂挂），与它无关的响应继续办理；跟进的更正（“刚才说反了”）挂到同一歧义单，不擅自作废其它响应。
- **准备接受 ≠ 已确认**：协调员“准备接受”只登记为就绪、不占容量；只有值班 `confirm` 后才占用。
- **整组与独立**：整组意向缺段时整组不确认；撤回其中一段会使同组其它段整组失效、释放容量并标记可重排（附替代时段）；
  独立意向可逐段接受。
- **容量竞争**：自由容量不足时系统**无权自动确认**，列明竞争的占用方；容量释放后重算并提示“机会重开”，仍需值班明确确认。
- **撤回权限与来源**：撤回已确认承诺需 `revise`（授权文本或值班确认才能改变已确认承诺）；
  来源不明的撤回不释放任何容量，转人工。
- **补发去重**：同发话人、同规范化文本且引用相同的补发副本不重复受理、不再次占用容量；真正修改才重新审阅。

## 代码结构

```
scripts/
  inspect.mjs            # 资料读取与记录数检查
  rehearsal.mjs          # CLI 入口：回放 + 报告 + 交接回查
  lib/
    timeutil.mjs         # 跨午夜时间、中文数字/时长、时槽切分
    resources.mjs        # 站点/别名/类别口径与例外
    parser.mjs           # 中文通知 → 带原句引用的结构化意图
    ledger.mjs           # 站点×时段容量台账与历史时点重建
    engine.mjs           # 时序处理、权限、歧义、去重、整组联动、交接
    report.mjs           # 人工可读的中文文本渲染
test/                    # node:test 规则测试（38 项）
```
